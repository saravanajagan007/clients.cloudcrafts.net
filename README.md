# clients.cloudcrafts.net

**CloudCrafts Client Portal & Infrastructure Dashboard**

A state-of-the-art, high-performance client portal designed for managing cloud servers, deployment pipelines, support tickets, API credentials, and billing invoices.

---

## Key Features

- ⚡ **Infrastructure Monitoring:** Real-time health, CPU/RAM utilization metrics, active instances, and bandwidth usage tracking.
- 🚀 **Server Management:** View hosted servers (AWS, DigitalOcean, Hetzner), check status, toggle power state, and inspect logs.
- 🔑 **API Key Vault:** Securely inspect, copy, and manage environment credentials & API tokens.
- 📄 **Billing & Invoices:** Download monthly subscription statements and breakdown usage.
- 💬 **Support Center:** Interactive ticket management system with real-time response previews.
- 🎨 **Glassmorphism UI:** Built with dark-mode aesthetic design tokens, smooth animations, and responsive layout.

---

## Tech Stack

- **Frontend:** HTML5, Modern Vanilla CSS3, ES6+ JavaScript
- **Design System:** Custom CSS Grid/Flexbox, Glassmorphism, Google Fonts (`Inter` & `Outfit`)
- **Repository:** https://github.com/saravanajagan007/clients.cloudcrafts.net

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/saravanajagan007/clients.cloudcrafts.net.git
cd clients.cloudcrafts.net

# Run locally
npm start
```

Open `http://localhost:3000` in your browser.
